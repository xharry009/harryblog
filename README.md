# Django Blog Web App

A clean, full-featured blog platform built with Python and Django framework, styled with a custom Neon theme, User Authentication, and PostgreSQL database.

## Features
- User Registration & Authentication (Login/Logout)
- Complete Blog Post CRUD (Create, Read, Update, Delete)
- Neon Aesthetic UI Layout & Responsive CSS
- Blog post commenting system
- Deployed live on Render

## Tech Stack
- **Backend:** Python 3.12, Django 5.x
- **Database:** PostgreSQL / SQLite3
- **Frontend:** HTML5, CSS3
- **Deployment:** Render
